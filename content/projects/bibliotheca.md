## Overview

Bibliotheca is an offline-first, business-agnostic component library and document editor framework designed with React 19, TypeScript, Tailwind CSS v4, and Bun.

Engineered with complete separation of concerns, Bibliotheca enforces strict token discipline and avoids hardcoded domain assumptions. Every visual component accepts both top-level styling and granular internal element slot overrides, delivering unparalleled adaptability across complex enterprise workflows.

## Key Capabilities

- **Offline-First Document Engine**: High-DPI DOM capture, multi-page vector PDF compilation with native link annotations, and client-side JSON state serialization.
- **2D Spatial Pan/Zoom Viewport**: Infinite canvas coordinate engine with mouse-wheel zoom centering, spacebar panning, and customizable grid overlays.
- **7 Signature Accent Palettes**: Amber Gold, Lateralis Teal, Classic Royal Blue, Executive Navy, Forest Emerald, Burgundy Rose, and Obsidian Slate with dual-mode light/dark token maps.
- **Zero-Compromise Accessibility**: 100% pass rate in Playwright Axe WCAG 2.1 Level AA automated audits.
- **Subpath Package Architecture**: Dedicated export entrypoints for `/tokens`, `/ui`, `/editor`, `/preview`, and `/export`.
