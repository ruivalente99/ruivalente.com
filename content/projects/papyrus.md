## Overview

PAPYRUS (Architectura Vitae) is an offline-first, dynamic multilingual resume and CV management engine designed with Next.js 15, React 19, TypeScript, and Tailwind CSS.

PAPYRUS bridges the gap between modern reactive web interfaces and traditional LaTeX typeset documents. Users can manage complex bilingual profiles, switch between starter templates, run real-time quality linting, and compile ATS-optimized vector PDFs directly within the browser.

## Key Capabilities

- **Bi-Directional LaTeX Engine**: Import existing TeX resumes and export clean, compilable LaTeX code with complete font and layout alignment.
- **Interactive PDF & Page Break Engine**: Millimeter-precision A4 dimensions (794px × 1123px at 96 DPI) with automated page break avoidance and embedded clickable hyperlinks.
- **Multilingual Data Architecture**: Deep internationalization with instant bilingual English and Portuguese toggling for every role, bullet highlight, and skill category.
- **Preset Starter Templates**: Lateralis (split-column portfolio), Classic (LaTeX academic ATS), and Matrix (executive competency grid).
- **Offline Storage & Multi-Profile Management**: Seamless local JSON seed backups and multi-profile workspace switching.
