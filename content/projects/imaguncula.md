## Overview

Imaguncula is an offline-first SVG asset workbench and sticker generator built with Next.js 15, React 19, and Bun.

Engineered for designers and developers needing rapid icon transformations, Imaguncula provides automated dilation algorithms for sticker borders, SVG optimization, and batch asset export workflows.

## Key Capabilities

- **Vector Dilation Engine**: Real-time convex and contour outline generation for physical and digital sticker assets.
- **Client-Side Asset Bundler**: Batch export to multi-resolution PNGs, SVGs, and bundled ZIP archives using JSZip.
- **Offline PWA Capabilities**: Complete functionality without an active network connection using client-side service workers.
- **Precision Typography & Scale**: Scalable vector previews with customizable canvas grids and dark/light inspection viewports.
