## Overview

Sappientus is a modern digital document workflow and certificate generation platform built with Next.js 16, React 19, LibSQL/Kysely, and Better-Auth.

Designed to eliminate administrative bottlenecks in academic and organizational credential management, Sappientus provides end-to-end verification, automated PDF generation with embedded security seals, and role-based administrative dashboards.

## Key Capabilities

- **Lightweight Database Architecture**: Embedded LibSQL edge storage queried with type-safe Kysely query builders.
- **Secure Authentication**: Multi-role user authentication and session management powered by Better-Auth.
- **Automated Certificate Compiler**: Client and server-side PDF generation integrating custom typography (Linux Libertine) and cryptographic verification seals.
- **Component System**: Styled using `@ruivalente99/bibliotheca` primitives for responsive layout, accessibility, and uniform design tokens.
